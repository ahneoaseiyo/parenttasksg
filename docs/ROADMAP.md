# ParentTask SG roadmap

## Phase 1: repository and governance
- Extract existing source ZIP into normal tracked files.
- Verify npm ci, npm run build, and API health check.
- Establish tests and CI with pinned Node version.
- Review dependencies and exposed secrets.
- Establish issue and PR templates and owner approvals.

## Phase 2: secure functional pilot
- Replace simulated extraction with evaluated extraction and human confirmation.
- Implement identity and tenant/resource authorization.
- Introduce durable database and migrations.
- Add test coverage, accessibility checks, privacy controls and deletion mechanisms.
- Pilot only with consent and reviewed safeguards.

## Phase 3: evidence and outreach
- Measure user value against existing school communication tools.
- Prepare evidence-backed proposal; independently verify the appropriate MOE/GovTech/ECDA pathway.
- External outreach requires founder approval.
